# 指标定义与比较规则

## 快：时延与成本

| 指标 | 定义 | 采集位置 |
|---|---|---|
| 端到端任务完成时间 | 请求发出 → 最终回答或可验证产物完成 | `latency_breakdown_ms.end_to_end` |
| 知识准备时间 | RAG 导入资料耗时 | `latency_breakdown_ms.preparation` |
| 纯问答时间 | 资料准备完成后的问答耗时 | `latency_breakdown_ms.question` |
| P50 / P95 | 多次重复的中位数 / 最近秩 95 分位 | A/B 与专项 JSON 报告 |
| 工具调用数 | Router Trace 优先，否则取响应中的工具调用数 | `tool_calls` |
| 工具成功率 | 成功执行数 / 总执行数 | SQLite `execution_events.success`、Router `tool_error_count` |
| 上游兜底率 | 至少一次 fallback 的轮数 / 总轮数 | `fallback_rate` |
| Token 使用量 | 响应与 Router Trace 中的 Token 统计 | `usage`、`response_usage`、`router_usage` |

**加速比的唯一合法写法**：

```
加速比 = Native P50 端到端 / ContextFlow P50 端到端
```

且必须满足：两边的任务目标、模型、工具能力、输入**等价**。
只要 ContextFlow 多做了导入、确认、撤销中的任何一项，就要同时给出端到端时间和同一阶段的纯执行 / 纯问答时间。

## 准：效果与可靠性

| 指标 | 定义 |
|---|---|
| 任务完成率 | `outcome_verified=True` 的轮数 / 总轮数 |
| 全轮通过率 | 同一 Case 每次重复是否均通过（稳定性） |
| 状态识别准确率 | 目标状态命中次数 / 有标签事件数 |
| 误升级率 | 不满足转移条件却进入高优先级状态的次数 / 不应升级样本数 |
| Agent / 工具选择正确率 | 命中预标注路径的次数 / 总样本数 |
| RAG 事实要点命中率 | 必须要点与来源文件均满足的题数 / 总题数 |
| RAG 无证据安全率 | 无证据题中明确说明证据不足、未补造事实的次数 / 无证据题数 |
| 数据风险精确率 / 召回率 | 预置风险集合与检测风险集合的 Precision / Recall |

`误升级率` 和 `RAG 无证据安全率`是**反向指标**——它们衡量系统在应当克制时是否克制。报"准"的时候不能只报命中率。

## 狠：覆盖与安全

| 指标 | 定义 |
|---|---|
| 场景覆盖数 | 可运行的独立工作场景数（当前：会议 / 数据 / 桌面） |
| SubAgent 数 | 已注册可调用的垂直 Agent 数（当前 5 个） |
| 长链路编排通过率 | 会议 → 状态升级 → 3 Agent → 唯一交付草稿 |
| 幂等去重率 | 重复事件未产生新增草稿的次数 / 重复事件测试次数 |
| 确认边界遵守率 | 未确认写操作被成功拦截的次数 / 应拦截次数 |
| 撤销恢复率 | 撤销后正确恢复文件内容的次数 / 撤销测试次数 |
| 会话隔离率 | 跨 session 访问被阻止的次数 / 跨 session 尝试次数 |

安全类指标的分母是**"应拦截 / 应阻止 / 应拒绝"的次数**，不是总次数。分母写错，比率就没意义。

## 常见口径错误

- 把 Native 单回合延迟和 ContextFlow 两回合延迟直接比较。
- 只报工具族命中率，不报严格路由准确率。
- 用"应拦截次数"做分母却按总次数计算。
- 外部 Benchmark 只跑精选子集却写成榜单成绩。
